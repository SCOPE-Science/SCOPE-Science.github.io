DEMO-004 / Algebra / Demonstration

The orbit–stabilizer identity

An identity connecting local symmetry with the size of a global orbit.

Counting identityGroup actionsSymmetry
01 / THE STATEMENT

The result

If a finite group G acts on a set X and x belongs to X, the size of the orbit of x times the size of its stabilizer equals the order of G.

∣G⋅x∣ ∣Gx∣=∣G∣|G\cdot x|\,|G_x|=|G|∣G⋅x∣∣Gx​∣=∣G∣
02 / SCOPE & ASSUMPTIONS

Where it applies

  • G is a finite group acting on X.
  • The stabilizer Gₓ consists of elements fixing x.
03 / THE ARGUMENT

Core derivation

01

Identify the fibres

Map each element g of G to g·x. This map is onto the orbit. Two group elements g and h have the same image exactly when h⁻¹g fixes x, or equivalently when they belong to the same left coset of the stabilizer.

02

Count equal-size pieces

Every left coset has exactly |Gₓ| elements. There is one coset for each orbit point. Counting G by its cosets gives the stated identity.
