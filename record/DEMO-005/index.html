DEMO-005 / Combinatorics / Demonstration

The edge–vertex relation for finite trees

A simple structural invariant, with the one-vertex boundary case and inductive step made explicit.

Structural identityTreesInduction
01 / THE STATEMENT

The result

Every finite tree with n vertices has exactly n − 1 edges.

∣E(T)∣=∣V(T)∣−1|E(T)|=|V(T)|-1∣E(T)∣=∣V(T)∣−1
02 / SCOPE & ASSUMPTIONS

Where it applies

  • A tree is a finite, connected, acyclic, simple graph.
  • The tree has at least one vertex.
03 / THE ARGUMENT

Core derivation

01

Find a leaf

For n > 1, take a longest simple path. An endpoint has no neighbour outside the path, since that would extend it, and no additional neighbour on the path, since that would create a cycle. Thus the endpoint has degree one.

02

Induct on the number of vertices

The one-vertex tree has zero edges. Removing a leaf and its unique incident edge leaves a tree on n − 1 vertices. By induction it has n − 2 edges; restoring the removed edge gives n − 1.
